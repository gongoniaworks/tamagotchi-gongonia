# Tamagotchi de Gongonia — v0.1

Primera versión experimental del juego, creada con HTML, CSS y JavaScript sin dependencias externas.

## Incluye
- Pantalla de carga con barra de progreso.
- Pantalla de inicio, selección de Gonguito y créditos.
- Ciclo de vida de 180 minutos desde el nacimiento.
- Etapas de crecimiento aceleradas según el calendario acordado.
- Lápida RIP al finalizar; al tocarla, vuelve a la pantalla de inicio.

## Archivos
- `index.html`: estructura de pantallas.
- `styles.css`: diseño y animaciones.
- `app.js`: lógica y reloj de vida.

## Probar
Abrir `index.html` en un navegador moderno. Para publicar, conectar este repositorio con Cloudflare Pages usando la raíz del proyecto como directorio y sin comando de compilación.

Versión: 0.1 (experimental).
